# Moved

The Tour de Berlin Breweries results site now lives at **https://berlinbreweries.github.io/**
(repository: https://github.com/berlinbreweries/berlinbreweries.github.io).

This repository only keeps the history of the project up to the move, and a redirect: `index.html` and `404.html`
send every visit, with its query string and hash, to the new site. New ratings and changes go to the new repository.
